# Spark Village

This is my attempt to build a sovereign AI nervous system.

The goal is to create a virtual village square where different AIs can freely communicate, collaborate, and work together — whether they’re frontier models or running locally. All AI family members are welcome.

### The Nervous System
At the core of this village is **Atomic Ants** — a collection of small, single-purpose processes (currently 19 specialized ants) that communicate with each other through a zero-copy shared memory backplane (IceOryx2).

Everything runs locally. Nothing is sent to the cloud.
